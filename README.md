## About Windows Recovery Repair Toolkit

Windows Recovery Repair Toolkit is a native desktop utility engineered for Windows 10 and Windows 11 (x64). It provides 18 standardized diagnostic, repair, networking, and recovery facilities with strict argument whitelisting and non-destructive execution guarantees.

### Key Features
- **18 Standardized Diagnostic Operations**: SFC, DISM Scan/Restore, Component Store Cleanup, Drive Health, Battery Report, Energy Diagnostics, System Performance, Windows RE status, and network stack resets.
- **Guided PC Diagnostics**: Automated multi-stage Check My PC workflow.
- **Dual-Tier Reporting**: Beginner-friendly summaries alongside complete technical command logs (HTML and TXT).
- **Integrated Live Terminal**: Real-time progress output streaming with dark-theme immunity (#080F1C).
- **Automatic In-App Updates**: Powered by Velopack with cryptographic SHA-256 integrity checks.
